# Interview Studio 0.2.9 alpha

## 전형 단계 기반 질문 구성

- 질문 초점 설정을 제거하고 전형 단계가 질문 구성을 결정하도록 단순화했습니다.
- 질문을 `순수 CS`, `포트폴리오 연계 CS`, `포트폴리오 경험`, `적합성`으로 분리했습니다.
- 1차 기본 5문항은 순수 CS 3문항, 포트폴리오 연계 CS 1문항, 포트폴리오 경험 1문항으로 구성합니다.
- 2차 기본 5문항은 순수 CS 1문항, 포트폴리오 연계 CS 1문항, 포트폴리오 경험 2문항, 적합성 1문항으로 구성합니다.

## 순수 CS 컨텍스트 격리

- 순수 CS 질문은 별도 LLM 호출로 생성합니다.
- 해당 호출에는 프로필 원문, 프로젝트 내용, 포트폴리오 출처를 전달하지 않습니다.
- 직무, 경력 수준, 기술 스택만으로 지원자가 기본 지식을 알고 있는지 검증합니다.
- 포트폴리오 연계 CS는 실제 구현 선택의 배경 원리와 트레이드오프를 묻는 별도 카테고리로 검증합니다.

## 검증

- 1차·2차 면접의 카테고리별 문항 수 테스트
- 제거된 질문 초점 설정의 하위 호환 파싱 테스트
- 순수 CS 호출에 프로필 컨텍스트가 포함되지 않는지 확인하는 서비스 테스트
- 전체 타입 검사, 자동 테스트, 프로덕션 빌드
