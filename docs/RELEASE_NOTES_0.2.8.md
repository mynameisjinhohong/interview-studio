# Interview Studio 0.2.8 alpha

## 질문 다양성과 전형별 구성

- 같은 프로필·회사·직무의 최근 세션 질문을 새 질문 생성의 제외 목록으로 사용합니다.
- 질문 계획 내부에서도 같은 핵심 역량과 질문 각도를 반복하지 않도록 강화했습니다.
- 전형 단계를 질문 생성 입력에 직접 전달합니다.
- 자동 추천은 1차 면접을 CS 기본기 중심, 2차 면접을 포트폴리오·프로젝트 심층 중심, 임원 면접을 협업·적합성 중심으로 구성합니다.
- `자동 추천`, `기초 CS·포트폴리오 균형`, `기초 CS·기술 기본기 중심`, `포트폴리오·프로젝트 심층 중심` 설정을 추가했습니다.
- 질문마다 `cs`, `portfolio`, `fit` 카테고리를 구조화하고 요청 비율과 다르면 재생성합니다.

## 종료와 최종 평가

- 답변 전사·다음 질문 결정과 최종 종합 평가를 서로 다른 진행 문구로 표시합니다.
- 마지막 답변의 녹화 조각을 확정한 뒤 카메라와 마이크를 즉시 해제합니다.
- 최종 평가는 60초 전체 제한과 비활성 제한 없이 실행합니다.
- 평가 경과 시간과 `평가 취소` 버튼을 추가했습니다. 취소 시 완료 답변과 녹화를 보존한 부분 결과를 생성합니다.

## 검증

- 전형 단계별 질문 비율과 사용자 명시 초점 우선순위 테스트
- 동일 회사·직무·프로필 최근 질문 제외 테스트
- 최종 평가 무제한 실행 및 사용자 취소 테스트
- 전체 타입 검사, 자동 테스트, 프로덕션 빌드
