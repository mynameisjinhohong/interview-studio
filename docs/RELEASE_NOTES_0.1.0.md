# Interview Studio 0.1.0 alpha

Windows와 macOS에서 로컬 AI CLI를 이용해 한국어 기술·회사 면접을 연습하기 위한 첫 개인용 alpha입니다.

주요 기능:

- 포트폴리오 파일·URL 수집과 구조화 컨텍스트 생성
- Codex·Claude·Gemini CLI 연결 및 공개 자료 조사
- 기술 면접·회사 면접, 연습·실전 모드
- 음성 질문, 로컬 Whisper 전사, 동적 꼬리 질문
- 선택적 720p 카메라 녹화
- 문항별 평가, PDF·MP4 내보내기, 점수 추이와 약점 복습
- Windows 설치 파일에 FFmpeg와 whisper.cpp 실행 파일 포함

이 빌드는 코드 서명하지 않은 prerelease입니다. 중요한 원본 자료는 별도로 백업하고 실제 채용 면접이 아닌 연습 용도로 사용하십시오.
