# Interview Studio 0.2.5 alpha

## 한국어 면접관 음성 관리

- 설정과 최초 준비 화면에서 현재 설치되어 실제 사용할 수 있는 한국어 음성을 모두 표시합니다.
- Windows OneCore 음성이 있더라도 SAPI 음성 검색을 생략하지 않아, 별도로 설치된 후보가 숨겨지지 않습니다.
- Supertonic 2 로컬 고품질 음성 팩을 앱 안에서 선택 다운로드할 수 있습니다.
- 한 번의 약 263MB 모델 다운로드로 한국어 여성 5종과 남성 5종을 추가하고, 이후 오프라인에서 질문 음성으로 사용합니다.
- 다운로드를 마치면 첫 번째 고품질 음성이 선택되며, 샘플을 들은 뒤 바로 적용할 수 있습니다.

Supertonic 2 모델은 OpenRAIL-M 라이선스로 제공됩니다. 모델은 Interview Studio의 로컬 데이터 폴더에 저장되며 `모든 데이터 삭제` 시 함께 제거됩니다.

## 검증

- 전체 자동 테스트 43개 통과(플랫폼/선택적 통합 테스트 제외)
- 실제 Supertonic 2 모델 다운로드 및 한국어 WAV 생성 통합 테스트 통과
- TypeScript 타입 검사와 프로덕션 빌드 통과
