# Interview Studio 0.2.1 alpha

Windows 면접 준비 과정의 장시간 LLM 조사와 사용자 취소 흐름을 개선한 패치 빌드입니다.

주요 변경 사항:

- 회사·기술 자료 조사와 본 질문 생성의 60초 고정 타임아웃 제거
- 구조화 출력을 기다리는 동안 경과 시간 표시
- `준비 취소` 버튼으로 실행 중인 CLI 하위 프로세스 즉시 종료
- 다른 화면으로 이동할 때 진행 중인 준비 작업 자동 취소
- 인증·네트워크·CLI 비정상 종료는 기존처럼 즉시 오류 처리
- 취소 신호가 재시도로 이어지지 않도록 CLI 실행 계약 보강
- 장시간 실행 및 취소 동작에 대한 회귀 테스트 추가

코드 서명하지 않은 개인용 prerelease입니다. Windows SmartScreen 또는 macOS Gatekeeper 경고가 나타날 수 있습니다.
