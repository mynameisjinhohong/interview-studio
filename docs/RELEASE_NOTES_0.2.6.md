# Interview Studio 0.2.6 alpha

## STT 모델 다운로드 수정

- Hugging Face Xet CDN의 객체 ETag를 모델 파일 SHA-256으로 오인해 정상적인 `small` 모델이 무결성 검증에 실패하던 문제를 수정했습니다.
- `base`, `small`, `medium` 모델마다 공식 파일 크기와 SHA-256을 고정하고 실제 다운로드 결과를 두 값으로 검증합니다.
- 중단되거나 손상된 다운로드는 계속 거부하며 `.partial` 임시 파일을 자동으로 정리합니다.
- STT 서비스가 모델 폴더를 직접 준비하므로 초기화 순서와 관계없이 다운로드할 수 있습니다.

## 검증

- 공식 `small` 모델 487,601,967바이트 실다운로드 및 SHA-256 검증 통과
- 정상 CDN ETag와 파일 SHA-256이 서로 다른 회귀 사례 자동 테스트 추가
- 잘린 파일과 잘못된 해시 거부 테스트 추가
- Windows 빌드에서 실제 `small` 모델 다운로드 통합 테스트 실행
